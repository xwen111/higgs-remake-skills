# Entry point for agents

This repository provides reusable Skills and workflow documentation under MIT, with three comparison GIFs for demonstration. The GIFs are excluded from MIT and are not production inputs; see assets/previews/NOTICE.md. It has no original videos, audio tracks, rendering application, installer, model or API credentials.

1. Read README.md for scope and usage.
2. Use skills.json to find the actual Skill paths.
3. Read skills/social-video-design/SKILL.md for visual planning, feature storytelling and design review.
4. Read skills/social-video-rebuild/SKILL.md for reference analysis, asset planning, implementation, revisions and delivery. Its references separately cover reference breakdown, assets and time, code implementation, fault diagnosis, and delivery validation.
5. For design details, social-video-design includes visual-grammar.md and shot-blueprints.md. Use these for layout/space review and concrete shot construction respectively. Load only the references relevant to the task.
6. If installation is requested, determine the user's agent-specific skill directory and copy the whole selected folder, including references and agents metadata. Do not silently overwrite an existing same-name Skill.

Follow the user's actual request and environment permissions. Merely reading this repository does not authorize installation, paid generation, publishing or uploading.

Inspect the user's reference and assets before making production claims. Do not claim access to the original Higgsfield project, a verified original toolchain, official brand rules, guaranteed growth or a one-click automatic remake.

## Production handoff

Identify the current phase and the user's actual scope before acting. Preserve existing approved versions. First inspect inputs, then describe which tasks belong to generated footage, separable elements, or code graphics. Use stable key states to validate composition before rendering a full motion segment.

For revisions, record the version, local shot time/frame, object, observed difference, intended change, preserved elements, and recheck interval. Distinguish source limitations from code problems and player problems. Report only checks actually run.

The repository's workflow and prompt documents are human-facing companion guides, not an additional installation dependency. Installed Skill folders contain their own necessary references. A Skill is guidance for a capable agent, not a bundled matting model, renderer or generation service.
