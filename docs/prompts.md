# 直接交给 Agent 的话术

根据当前任务选一段，不需要每次全部执行。

## 拆参考

```text
请先分析我提供的参考视频，不开始复刻。
按场景给时间点、关键截图、主体动作、构图、运镜、速度变化。
把 AIGC 素材和代码后期分开，列出文字与控件布局和动画状态。
整理成可交互 HTML，支持目录、放大、复制或下载。
观察到的效果和推测的实现方法分开说。
```

## 生成素材前

```text
根据这个镜头先告诉我需要提供什么素材，再给图片和视频提示词。
环境、角色、首帧分别考虑；需要纯环境时不要生成主角。
视频写清总时长、动作分段、机位、运镜、速度和光照。
精确文字、参数条和选框留给代码，不在生成视频里烙进去。
提前考虑后续放大、分层、换物与独立调速需要的输入。
```

## 做第一个镜头

```text
请读取 social-video-design 和 social-video-rebuild。
本次只制作这个镜头，主体用我的素材，参考片只用来分析和对比。
先给布局和关键状态，再重建进入、停留、变化与退出。
不要拿原片画面盖到我的素材上。
给中间结果、可观看输出和对比；缺素材时明确指出。
```

## 运动表面换字

```text
我有同一运动的空白、旧状态、新状态视频。
先检查时间与画面对齐，不直接切换整帧。
先给原画面、遮罩、清除后和合成后的关键帧。
局部替换跟随表面透视，处理反光、遮挡与运动模糊。
注意高光与尘土误选，检查连续帧后再渲染完整段。
```

## 更丝滑的具体修改

```text
请按时间点比较布局、进入时序、速度衔接、稳定停留与退出。
检查控件的字、外框、拖动点是否共享同一透视平面，
以及遮挡、阴影、模糊、图层交接是否自然。
先列出差异，给修改前后关键帧，再渲染短段。
保持其他已确认部分的当前版本。
```

## 合并和交付

```text
先列出每个确定版镜头的文件、版本、顺序和时长，再合并。
按我的要求交 MP4、完整MOV、透明动效层MOV及横竖对比。
透明层说明包含什么，参考有进度映射时注明。
分别检查解码、时间戳、Alpha和衔接，只报告实际完成的检查。
```
