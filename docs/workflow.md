# 完整工作流：从参考到可交付的自己的片子

这是一套供用户和 Agent 协作的制作方法。仓库不附生成模型、媒体处理环境或输入素材；真实制作前需要检查 Agent 能访问哪些文件和工具。

可以从任意阶段接手：只拆片就交拆解；已有工程就沿用；用户只圈了一个问题就先定位它，不重做所有镜头。

## 第一步：明确本次要交什么

把目标写成一个短任务：参考的哪一段、自己的主题/产品、目标画幅、时长、是否保留完整动作、是否需要透明层或对比片。已经说明的信息不必反复询问。

让 Agent 先列已确认版本和现有素材。没有工具链时，用一段短素材加一个文字动画，实际输出可播放文件，验证素材、字体、渲染与编码。不要只接受“环境已准备好”的文字结论。

设计新片时先用 [social-video-design](../skills/social-video-design/SKILL.md)；具体重建与返工用 [social-video-rebuild](../skills/social-video-rebuild/SKILL.md)。两者可以协作，不要求每次全套运行。

## 第二步：拆成带时间与截图的制作说明

先找建立画面、进入、操作、变化、结果和退出，再对快速转场加密查看。记录主体动作、摄影、布局、空间关系和不变项。

建议交付HTML：有目录、关键截图、时间点、AIGC任务、代码任务、素材清单和待确认项。截图能放大/复制/下载；复制受限时要有回退。不要用一大段泛泛的文字替代可观看的拆解。

完成标准：你能据此知道下一步生成什么、后期改哪里、怎样判断做对。原片软件和字体未知就注明，不影响用自己的方法重建。

## 第三步：先看后期需求，再生成素材

| 后面要做的事情 | 提前准备 |
|---|---|
| 主体放大、移动 | 足够清晰的主体与可补空位的背景 |
| 图层展开 | 透明元素、完整背景、可信阴影 |
| 局部换文字/物体状态 | 同一基础视频的旧、干净、新状态 |
| 目标单独慢动作 | 完整场景、去掉目标的版本、可分离的动作 |
| 白天变夜晚 | 包含真实照明阶段的素材，动作速度另行控制 |
| 年代变化 | 接近机位与布局的状态变体 |

视频模型主要提供连续内容，代码主要控制精确图形。纯场景图、角色图、视频首帧可以不同。生成提示词写清动作顺序、运镜与速度，不只堆“电影感”。

素材到手后，先在几个时间点对比。如果变体不一致，优先解决对齐与输入条件，不把整帧切换假装成局部替换。比例不符时考虑重新构图、扩图或用户接受的裁切，不默认虚化填边。

## 第四步：做一个镜头的稳定状态

先摆好主体、标题、说明和控件。检查最终缩小尺寸的可读性，文案变长时重新排版。确定控件属于屏幕HUD、对象标记、表面纹理还是空间图形，再处理透视与遮挡。

抠图/换物先看中间结果：透明主体、干净背景、遮罩、清除后、合成后。不要等全片渲染完才发现人物底下还有一块方形旧背景。

稳定帧成立后，再连接进入、变化和退出。运动有明确先后与速度衔接；同一控件的字、环、标签一起变换。快速过渡可以加适当模糊，但不能靠全程糊掉来遮盖低清和接缝。

## 第五步：明确时间，保留必要动作

分开输出时间、源素材时间和图形状态。局部慢动作给目标和背景各自时钟；遮罩、跟踪和阴影也要用正确时间取样。

时长冲突时，先去无用引导和尾部停留，再考虑温和调速或延长。用户要求的跑动、转身、落地等动作不能为了卡秒数剪没。对比若将原片按进度重映射，明确标注。

## 第六步：同步对比与具体返工

用同帧对比看布局，用连续播放看动作；慢放看转场和边缘，正常速度看整体观看体验。尽量使用合成的单条对比视频，减少双播放器缓冲带来的假错位。

每轮修改记录：版本、时间、对象、差异、目标、保留项和复查点。例如“2秒处速度环有角度但字没变，整体投影一起改；保留数值和位置”。

异常先查文件帧，再查网页缓冲。源素材静止、时间映射停住、渲染缓存残留和播放器没准备好，是不同问题，不应统一靠重新加速来解决。

## 第七步：确认版本，再合并

每个确定镜头保留版本与来源映射。合并前列出顺序、帧数、fps/PTS和时长，避免混入调试版。统一帧率可能改变原生帧，需要有意识地选择重采样方法。

配乐按用户授权处理，检查镜头延长后的连续性，不自动公开参考音轨。透明动效层是否带音频要说明。

## 第八步：交付与范围检查

按请求交MP4、完整MOV、透明动效层MOV、横/竖排对比及工程。MOV后缀不保证透明，抽检编码后Alpha；完整MOV也不能误拿成只有UI的层。

报告实际做过的规格、解码、时间戳、视觉和播放检查。合并与确定版一致仅说明没有改掉已确认画面，不证明与参考片逐像素一致。

公开仓库另用上传清单：Skill与方法、展示GIF、原视频、配乐、角色和字体是不同范围。不能因项目用了MIT就把所有输入一并公开。
