# 参考片 → 自己的社媒短片

使用你有权处理的参考与素材。当前仓库公开流程，不分发生成素材，不要求固定模型或渲染框架。

## 开工前

告诉 Agent：你要做的产品/主题、参考视频、画幅、时长和已有素材。先让它检查能否访问视频、抽帧、处理图像和渲染。做一个小段验证再开做整片。

参考片看不到时，提供截图和时间段；不要让它假装已经观察完整视频。需要 AIGC 时由你选择生成工具；Skill 不绑定付费 API。

## 1. 拆解成网页

逐段整理“看到什么、怎么动、什么时候变、为什么这么设计”。关键截图和时间点放进 HTML，可目录跳转、放大、复制。复制受限时有备用方式。

观察结果与实现猜测分开记录。原片的字体或软件没证据时，不写成确定事实。

## 2. 根据后期目标准备输入

- 需要放大：准备足够清晰的独立人物/物体，而不是放大小像素后强行锐化。
- 需要移走主体：准备干净背景，修补空位与原有阴影。
- 需要换状态：从同一基础视频派生变体，检查机位、运动和时序一致。
- 需要局部慢动作：提供移除目标的背景版本，目标与背景使用独立时间映射。
- 需要昼夜变化：提前考虑真实照明、反射与阴影，不只调整曝光。
- 需要时代变化：尽量保持可比较的构图、机位和空间布局。

生成提示词写总秒数、画幅、动作分段、机位/运镜、速度、光照、不生成的后期 UI。秒数是生成目标，需要检查实际结果。

## 3. 先看关键状态，再做完整动画

把素材和图形任务分开。自然动作、运镜、毛发与复杂光照可在 AIGC 素材中准备；精确文字、参数、线框和控件由代码绘制。

先看稳定状态能否读懂，再补进入与退出。检查一个控件的字与外框是否共享透视、图层是否有合理遮挡、运动是否有交接。不要只靠提高 fps 或全段加速解决节奏问题。

## 4. 展示中间过程

抠图给独立元素与透明预览；换贴纸给遮罩、擦除后、新状态合成后；调速给目标与背景各自的时钟。边缘、反光、尘土、阴影要看连续帧。

“像素级处理”不等于所有帧天然完美。让 Agent 指出失败位置和需要的补充素材，而不是跳过中间结果直接宣称成功。

## 5. 对比审片

给具体时间点和问题：标题位置、出现早晚、透视、影子、接缝、停顿。最终同步对比尽量用合成的单条视频，避免双播放器因缓冲不同而假错位。

有异常先看导出帧，再查播放器启动。对比中若参考被调速或重新映射，清楚注明。用户允许保留动作优先时，不再偷偷把它压回原片时长。

## 6. 固定版本，再合并

保留每镜采用的版本、帧数、fps或真实时间戳、时长和顺序。不要为统一 fps 静默改变已确认动画。

按需交 MP4、完整 MOV、透明动效 MOV、横排/竖排对比。透明层说明包含什么，不烙棋盘格；`.mov` 后缀本身不能证明 Alpha 存在。

解码、PTS、Alpha、像素一致性、目视和浏览器播放是不同检查。只报告实际做过的；“合并与确定版一致”不等于“复刻与原片像素一致”。
